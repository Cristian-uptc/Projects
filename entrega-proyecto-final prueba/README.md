# Entrega - Sistema de reservas de canchas deportivas

- diagrama-de-clases.png / .puml : diagrama de clases del paquete model
- court-reservations-server.jar : servidor (localhost, puerto 5000)
- court-reservations-client.jar : cliente (localhost, puerto 5000)
- server-project/ y client-project/ : codigo fuente de cada proyecto

Uso local: ejecutar primero el servidor y luego uno o varios clientes.
  java -jar court-reservations-server.jar
  java -jar court-reservations-client.jar
Administrador predefinido: admin / admin123.
